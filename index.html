Automation framework

In progress

A Java test automation framework built on Selenium WebDriver and TestNG using the Page Object Model. It keeps page locators and actions separate from test logic, so tests stay readable and pages can change without rewriting every test.

Built with Maven and Git, and designed to plug into a CI pipeline such as Jenkins or Azure DevOps.

View on GitHub
# Page Object Model layout
src/
├─ main/java/
│  ├─ pages/      # page objects
│  ├─ base/       # driver setup
│  └─ utils/      # waits, config
└─ test/java/
   └─ tests/      # TestNG tests
